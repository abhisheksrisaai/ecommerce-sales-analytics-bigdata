# Archive

This folder contains superseded or reference material that is no longer part of the active project.

## old_deliverables/
Earlier copies of DA-2 and DA-3 reports/slides created with registration number 23BLC1240. These were superseded by the final 23BLC1292 versions kept in `deliverables/DA2/` and `deliverables/DA3/`.

## old_generators/
Original DA-2 report/figure generators (`gen_report.py`, `make_diagrams.py`, `make_evidence_figs.py`) and the original DA-2 MongoDB loader (`mongo_loader_01.py`). They were replaced by the DA-3 generators in `src/utils/` and by `src.recommender.loader_and_recommender`, which produces the active NLP-aware recommendations.
